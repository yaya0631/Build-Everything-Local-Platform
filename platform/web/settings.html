Assistant

The Everything assistant appears inside the apps you choose. It can read the page, navigate, manage files and call the tools an app already provides. Without an AI provider it stays unavailable and the app keeps working normally.

Apps with a native assistant keep their own panel and tools; the shared assistant is available to the rest.

AI providers

Add a provider, paste its key, then choose which capabilities it should serve.

Routing

Send each capability to a specific provider, or let the first enabled provider that supports it answer.

Local by design. Account records and provider settings live in platform/data/everything.sqlite. AI requests go from this server to the endpoint you configure; apps never see provider keys. Existing apps keep their normal unavailable state until at least one provider can serve their request.
